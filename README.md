# gora-birthday-bot

Репозиторий с тестовой документацией и артефактами проверки Telegram-бота **"Жора"** (напоминания о днях рождения с фоновым планировщиком и хранением данных в SQLite).

---

## 🛠 Стек и инструменты
- **Test Management:** Test IT (проектирование тест-кейсов, наборов и проведение прогонов)
- **Bug Tracking:** Jira (декомпозиция требований в User Stories, заведение и трекинг дефектов)
- **Documentation:** Confluence (тест-план, матрица трассируемости, итоговый отчёт)
- **Environment & Deployment:** Python, SQLite, Telegram (`v7.4.4`), хостинг `fps.ms`

---

## Функциональное тестирование (`Build 1.0`)

Проверка базового пользовательского пути и фоновой логики бота: добавление, поиск, просмотр, редактирование и удаление записей о днях рождения, настройка часовых поясов и временных слотов, работа фонового планировщика рассылок (`JobQueue`), а также сохранность и восстановление данных в SQLite.
